# MediBook — Clinic Booking System

A patient appointment scheduling web app for private clinic chains, built by **Michelle Piper**.

## Features
- Doctor selection with availability status
- Interactive time slot picker
- Date selection and appointment booking
- SMS confirmation via Termii
- Upcoming appointments dashboard
- Patient health summary panel

## Tech Stack
`Django` `Python` `Vue.js` `Termii SMS` `PostgreSQL`

## Live Demo
Open `index.html` in your browser for the interactive frontend demo.
